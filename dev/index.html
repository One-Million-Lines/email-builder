📧 Email Builder — Development Demos

Each page loads the editor with a specific plugin wired to the local mock server.
Make sure to run the mock server first: node dev/mock-server.mjs

Quick start

# 1. Build the library (required before running demos)
npm run build

# 2. Start the mock backend server
node dev/mock-server.mjs

# 3. Open this page
http://localhost:3001/dev/
